# A3-07 Wallet RC1

Source: `ac12cf6e00ca704993b66fff51bc1c629605aeee`. Branch: `release/a3-rc1`.

This is a release candidate, not a production release. Privy dashboard recovery and existing-account mapping verification remain production blockers. The existing application ID and wallet-creation policy are unchanged.

Vercel Preview builds render a clearly paused login screen without initializing Privy. There is no customer sign-in, signing or automatic wallet creation in this RC Preview. Protected local development fixtures remain available only on loopback. The integrated fixture now includes gated Buy on both networks and gated Swap on Ethereum.

Automatic deployments for this RC branch are disabled in `vercel.json`: first provision branch-only Preview isolation, then explicitly deploy the exact Git SHA with a verified Preview target. Never use a Production target. Production variables, aliases and domains must remain untouched. Preview overrides blank unused historical credentials and the live Privy secret, disable Buy/Swap/Tron creation/send gates, and use a public read-only Ethereum RPC. Existing Preview-scoped 0x access may be used only for read-only provider validation.

The fresh RC audit identified Axios high-severity advisories in TronWeb's nested dependency. The dependency is overridden to the patched 1.20.0 release; no major SDK version changes. See the [Axios advisory](https://github.com/advisories/GHSA-c29m-xwm3-cm6r).

Physical iPhone/iPad Safari/PWA testing, real Privy continuity, authorized controlled transaction validation, provider staging configuration and distributed session/rate enforcement remain release gates. Buy and Swap production execution must remain disabled. No real transactions are part of A3-07.
